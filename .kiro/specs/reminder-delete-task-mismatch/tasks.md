# Implementation Plan

## Scope

Route only a single, named natural-language `delete_task` action through scheduled-reminder matching before the legacy local-task fallback. Reuse the existing owner, date, title-term, confirmation, revision, audit, and cancellation behavior. Bulk task deletion, explicit deterministic schedule cleanup, Calendar operations, reminder creation, and reminder delivery remain on their current paths.

Use fixed clocks, in-memory repositories, and test doubles for all automated checks. No external provider or persistent user configuration is required.
